# 灵蕴 AssetFlow · 游戏科学研发生产中台

> 面向 3A 单机游戏研发的资产管理与评审协同工具 —— 产品设计原型

---

## 一句话定位

为游戏科学（Game Science）黑神话新作（BMZ）团队设计的研发生产中台，解决**资产版本混乱、评审反馈断裂、风险不可视**三大痛点。

---

## 背景

3A 游戏研发中，一个 Boss 角色资产可能经历 20+ 次迭代、跨越角色/场景/特效/动画 4 个工种、产生上百条评审批注。现有工具（Jira + Perforce + 微信群）割裂了资产流与信息流——任务在 Jira、文件在 P4、反馈在微信，三者互不相通。

**灵蕴 AssetFlow** 把这些重新焊在一起。

---

## 产品设计

### 核心模块

| 模块 | 解决什么问题 |
|------|-------------|
| **工作台** | 制作人员一眼看清自己今天的资产、任务、被打回项和阻塞项 |
| **资产库** | 全项目资产统一检索，按类型/状态/负责人组合筛选 |
| **资产详情** | 资产全生命周期追溯：版本树 + 关联任务 + 评审返修时间线 |
| **任务看板** | 5 列拖拽看板（未开始→进行中→阻塞→待评审→已完成），阻塞列互斥检查 |
| **评审中心** | 主美/TA 在线批注 + 通过/返修双路径 + 返修项到期追踪 |
| **规范库** | 美术/动画/性能/外包/案例 5 类规范，引用统计驱动返修率下降 |
| **项目风险** | 逾期/高返修/积压/阻塞四维监控 + 按类型风险分布 |

### 设计决策

- **单文件 HTML MVP**：零依赖、Hash Router、CSS Design Token 系统，可直接在浏览器打开
- **深色+暗金主题**：匹配游戏研发工具的工业气质，Canvas #0E0F0F + Review Gold #C9A45B
- **数据驱动交互**：所有筛选/搜索/拖拽均基于模拟数据集运行，交互链路完整可验证
- **面向制作人员**：以角色美术陈磊为 persona，信息架构从"我今天要做什么"切入

### 技术栈

纯前端 · HTML5 + CSS3 + Vanilla JS · Hash Router · CSS Variables · Drag & Drop API · SVG 内联图标
